⚡ AVVIA IN 30 SECONDI
───────────────────────────────────────────────────────────────

OPZIONE 1 - Python (Consigliato)
$ cd melody-quest/
$ python -m http.server 8000
→ Apri: http://localhost:8000

OPZIONE 2 - Node.js
$ cd melody-quest/
$ npx http-server
→ Apri: http://localhost:8080

OPZIONE 3 - Live Server (VS Code)
1. Installa extension "Live Server"
2. Click destro su index.html
3. "Open with Live Server"

🎮 COME GIOCARE (5 STEP)
───────────────────────────────────────────────────────────────

1. APRI index.html nel browser
2. Clicca "INIZIA AVVENTURA"
3. Scegli un livello (1-7 epoche musicali)
4. Completa il QUIZ (5 domande, serve ≥80%)
5. GIOCA L'ARCADE:
   - Note cadono dallo schermo
   - Clicca al ritmo giusto
   - Sconfiggi il boss
   - Vinci il livello!

🔧 CUSTOMIZZA DIFFICOLTÀ
───────────────────────────────────────────────────────────────

Apri: js/game-config.js

Modifica questi valori:
- INITIAL_LIVES: 4 (aumenta per più vite)
- NOTE_FALL_SPEED: 0.015 (aumenta = più veloce)
- NOTE_SPAWN_RATE: 0.8 (aumenta = più note)
- QUIZ_PASS_SCORE: 80 (diminuisci per facile)

🐛 PROBLEMI?
───────────────────────────────────────────────────────────────

Canvas non appare?
→ Apri DevTools (F12) e controlla console per errori

Quiz non funziona?
→ Verifica che game-config.js sia caricato

Note non cadono?
→ Controlla NOTE_SPAWN_RATE > 0 in game-config.js

PNG non caricano?
→ Verifica cartella assets/images/ sia presente

Vedi QUICK_START.md per troubleshooting completo!
