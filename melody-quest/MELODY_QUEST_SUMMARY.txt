🚀 COME USARE
─────────────────────────────────────────────────────────────────────

1. NAVIGA CARTELLA:
   cd /mnt/user-data/outputs/melody-quest/

2. AVVIA SERVER (scegli uno):
   
   PYTHON:
   $ python -m http.server 8000
   
   NODE.JS:
   $ npx http-server
   
   VS CODE LIVE SERVER:
   - Installa extension "Live Server"
   - Click destro su index.html → "Open with Live Server"

3. APRI BROWSER:
   http://localhost:8000

4. GIOCA!
   - Clicca "INIZIA AVVENTURA"
   - Scegli livello (1-7)
   - Completa quiz (≥80%)
   - Gioca arcade
   - Sconfiggi boss
   - Vinci livello!
